Queries utilizadas para alimentar o dashboard de MAU do Hotmart App · Datasource: DH_ATHENA (Astrobox)
📊 Dashboard 📝 Queries SQL
Informações de Acesso

Como executar

Todas as queries abaixo são executadas no Astrobox (plataforma de dados Hotmart) usando o datasource DH_ATHENA.
Acesse: astrobox.hotmart.com → Selecione o datasource DH_ATHENA → Cole a query.

Os parâmetros de data (:begin e :end) devem ser substituídos pelos valores desejados no formato 'YYYY-MM-DD'.
MAU via Sparkle (eventos de UI do app)

1. MAU — Wallet, Pocket, Histórico de Saque e Saque (fluxo)

Retorna o MAU (Monthly Active Users) das funcionalidades principais do app, agrupado por mês e label de evento.
dh_sparkle 📊 Tabela: dh_sparkle.ui_view_view_open 👤 User ID: "user.id_security" 
SELECT
  DATE_TRUNC('month', CAST(hub_transaction_date AS DATE)) as mes,
  label,
  COUNT(DISTINCT "user.id_security") as mau
FROM dh_sparkle.ui_view_view_open
WHERE hub_transaction_date BETWEEN '2025-12-01' AND '2026-07-31'
  AND label IN (
    'open_wallet',
    'open_pocket',
    'withdraw_history_open',
    'withdraw_cash_account_confirm',
    'withdraw_cash_confirmed_order'
  )
GROUP BY 1, 2
ORDER BY 1, 2

2. MAU por Plataforma (Android/iOS) — Wallet, Pocket, Saque

Split de MAU por plataforma mobile para as funcionalidades que possuem o campo device.platform na sparkle.
dh_sparkle 📊 Tabela: dh_sparkle.ui_view_view_open 📱 Platform: "device.platform" 
SELECT
  DATE_TRUNC('month', CAST(hub_transaction_date AS DATE)) as mes,
  label,
  "device.platform" as platform,
  COUNT(DISTINCT "user.id_security") as mau
FROM dh_sparkle.ui_view_view_open
WHERE hub_transaction_date BETWEEN '2025-12-01' AND '2026-07-31'
  AND label IN (
    'open_wallet',
    'open_pocket',
    'withdraw_cash_account_confirm',
    'withdraw_cash_confirmed_order'
  )
  AND "device.platform" IN ('ANDROID', 'IOS')
GROUP BY 1, 2, 3
ORDER BY 1, 2, 3
MAU via dh_hotmart_app_wallet (tabelas específicas)

3. MAU — Extrato (Statement)

Usuários únicos que visualizaram o extrato no app.
dh_hotmart_app_wallet 📊 Tabela: dh_hotmart_app_wallet.statement_view 👤 User ID: ucode 
SELECT
  DATE_TRUNC('month', CAST(hub_transaction_date AS DATE)) as mes,
  COUNT(DISTINCT ucode) as mau
FROM dh_hotmart_app_wallet.statement_view
WHERE hub_transaction_date BETWEEN '2025-12-01' AND '2026-07-31'
GROUP BY 1
ORDER BY 1

Queries Auxiliares (Exploração)

10. Descobrir todos os labels de evento do app

Lista todos os eventos de UI registrados no app Hotmart. Útil para descobrir novas funcionalidades rastreáveis.
dh_sparkle 
SELECT DISTINCT label
FROM dh_sparkle.ui_view_view_open
WHERE hub_transaction_date >= '2026-07-01'
ORDER BY label

11. DAU (Daily Active Users) — Wallet vs Pocket

Contagem diária de usuários únicos por funcionalidade. Útil para identificar padrões sazonais e anomalias.
dh_sparkle 
SELECT
  COUNT(DISTINCT "user.id_security") as total,
  label,
  hub_transaction_date as data_evento
FROM dh_sparkle.ui_view_view_open
WHERE (label = 'open_wallet' OR label = 'open_pocket')
  AND hub_transaction_date BETWEEN '2026-07-01' AND '2026-07-31'
GROUP BY label, hub_transaction_date
ORDER BY hub_transaction_date, label
Notas Técnicas

Dicas de uso

  • Tabelas sparkle usam "user.id_security" (com aspas duplas, campo com ponto no nome) como identificador único de usuário.
  • Tabelas dh_hotmart_app_wallet usam ucode como identificador único de usuário.
  • O campo hub_transaction_date nas tabelas sparkle é varchar — precisa de CAST AS DATE para funções de data como DATE_TRUNC.
  • O campo hub_transaction_date nas tabelas wallet aceita filtro direto com string sem necessidade de CAST.
  • O campo "device.platform" na sparkle precisa de aspas duplas (tem ponto no nome). Valores: ANDROID, IOS.
  • O campo platform nas tabelas wallet é direto (sem aspas). Valores: ANDROID, IOS.
  • withdraw_history_open retorna MAU=0 para iOS — evento não instrumentado no iOS. Para dados iOS de histórico de saque, usar dh_api_report_vulcano.withdraw_history_show.
  • Badges/Journey (journey_view) pode ter dados muito baixos — feature parcialmente desativada em períodos.
